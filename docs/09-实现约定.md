## 9.1 EUI-NEO 致命约定

按踩过的次数排序，前 6 条是"不知道就一定浪费时间"的。

| # | 约定 | 为什么 |
| --- | --- | --- |
| 1 | `dslAppConfig()` 每帧被调 20+ 次：**禁**读盘 / 扫目录 / `Signal::set` / 写日志 | 任何 I/O 都会被放大成每帧 20 次。刷新只挂用户动作 |
| 2 | `ui.stack()` 内**不写** `.position()`，子元素用 `.x()/.y()` | 写了会被 stack 覆写，表现为"位置怎么都不对" |
| 3 | `<windows.h>` 的 `#define small char` → EUI 头在前，之后 `#undef small` | 否则 `small` 标识符全被替换 |
| 4 | `components::dropdown` 不可用、`segmented` 会压字 | 前者弹层被父级 clip 裁掉；后者宽度算错。一律自绘 + 根级 overlay |
| 5 | `ui.text` **不裁剪**：精确量宽用 `core::TextPrimitive::measureTextWidth/Size`（有缓存） | `wbTextW` 是 em 估算，纯 ASCII 高估三四成 |
| 6 | 窗口隐藏/最小化后**没有下一帧** → 状态机不能挂帧 | "等结果再画"的逻辑必须一帧内做完 |

其余细节：

| # | 项 | 做法 |
| --- | --- | --- |
| 7 | `dialog().content()` 的层级 = 声明顺序 | 铺满的底衬必须写第一句，否则盖住内容 |
| 8 | `components::switch` | `build()` 不写 position，**必须包 `ui.stack().position()`**；`size()` 宽度要含 label；`.trackSize(40,22)` 比默认 46×24 顺眼 |
| 9 | 底色分层 | 面板底 ~(38,38,46)；提亮用 0.175 / 0.185 / 0.215（0.132 反而更暗） |
| 10 | `virtualList` | 滚动复位要换「代次 id」；回调 row 的 `width` **已扣滚动条**，行内不要再减 |
| 11 | 原始字符串 | `R"(…)"` 里的 `)"` 是闭合符 → 以 `"` 结尾必须写 `R"(…fill=")"`，否则吃引号、SVG 静默空白 |
| 12 | `mouseArea` **没有** `.border()` | 用 `ui.rect().color().radius().border()` + 透明 `mouseArea` 叠层 |
| 13 | 图标一律图标字体 | `ui.text().icon(0xFxxx).fontSize().lineHeight(h)`。已验：`F0B0` 过滤、`F0E2` 撤销、`F07B` 文件夹、`F005/6` 星、`F013` 齿轮、`F021` 刷新、`F00C` 勾、`F00D` 关、`F054` 右箭头 |
| 14 | 行内对齐 | 同高行框 + `verticalAlign(Center)`；图标基线差靠截图量 ink 补常量（例 `kStarNudgeY=-2.5`）。**像素细节一律采样判定，别看缩略图目测**（开关旋钮目测判反过两次） |
| 15 | `screen.height` 是**窗口外框**（含标题栏，客户区矮 ~31） | 贴底布局必须多留 30 |
| 16 | `components::button` 字号默认 = 高 × 0.46 | 不写 `.fontSize()` 就跟着高度长；统一尺寸时务必显式给 |
| 17 | `components::toast` | `screen(w,h)` 要传**客户区逻辑尺寸**；`message` 高度写死 `height-50`，多行必须按 `textScale()` 现算；`ToastStyle` 默认 `theme::dark()`，必须 `.theme(uiTheme())` |
| 18 | **元素 id 禁与组件内部生成的子 id 撞名** | switch/checkbox/radio/slider/input 等组件内部生成 `<id>+".hit"/".track"/".knob"/".label"`（如开关 `loc.auto` 内部命中区就叫 `loc.auto.hit`）。interaction 状态按 id 索引，两个同 id 的 interactive 元素共享一份状态：hover 每帧被互相覆盖，`on=1/on=0` 每帧重复触发（一次会话 963 次、自激重组风暴），移开时 hide 被乱序淹没 → 浮窗残留。2026-11-03 汉化页标题命中区踩中，改 id `loc.auto.title` 修复 |
| 19 | **窄串（UTF-8）喂 `std::filesystem::path` / `fopen`，中文目录下会崩** | MSVC 的 `fs::path(const std::string&)` 按 **ANSI(GBK)** 解码，CRT 的 `fopen` 同样按 ANSI 解释路径字节。UTF-8 中文字节尾 ≥0x81 撞上后续 ASCII 字节 <0x40（`.`=0x2E、空格=0x20、数字=0x30~0x39）时 GBK 序列非法 → 抛 `std::system_error(1113)`「在多字节的目标代码页中，没有此 Unicode 字符可以映射到的字符」。**触发条件是启动器所在目录名**：`PXC 启动器` ✅ / `PXC 启.动器` ❌ / `PXC 启动器 v0.0.1` ❌（与空格无关，是字节序列）。两处必修：① 打开文件一律 `_wfopen(p.wstring())`（`pxc_io` 本来就是；`log.cpp` 2026-11-03 从 `fopen_s(UTF-8)` 改来 —— 原来中文目录下**日志整体静默失效，连崩溃记录都写不下**）；② 把路径当字符串交给 EUI 时同样会炸：`fontFamily` 含 `.` 即被当 ttf 路径，EUI 内部 `fs::path(窄串)` 抛异常 → 已在 `EUI-NEO-main/core/render/text.cpp::resolveFontFilePath` 加 `utf8Path()` 显式按 CP_UTF8 解码。现象：切到汉化页（字体预览）瞬间闪退、退出码 `0xE06D7363`（未捕获 C++ 异常）、无任何日志 |

### 9.2.3 工具使用的坑

- 多处改动**写 Python 脚本执行**（连发多条 Edit 可能 success 不落盘）。
- `python -c` 里别写反引号。
- 本机看不到 stdout → 写文件再 `Read`。
- GUI 进程撑不过一次工具调用 → 启动 → 操作 → 校验塞进同一次调用。
- `tasklist` 输出 GBK 解不了 → 改查日志与 json。
- PowerShell 从 Bash 调会被安全策略拦 → 用 Python + `ctypes`。

## 9.3 真机才暴露的坑

| 项 | 事实 |
| --- | --- |
| Steam 定位 | AppID **2299510**。本机 3 个库，PXC 只在 `G:\SteamLibrary`，**别只看主库 common**。链：注册表 `SteamPath`（正斜杠）→ `libraryfolders.vdf`（转义双斜杠）→ `appmanifest_*.acf`（**单**斜杠）→ `installdir` |
| 两种安装形态 | **Steam 版没有 `data/`**，语言在 `pack/locale.zip`（`en/` 仅 9 条目，无 `UI.json`）；itch 版只有 `data/locale/`，无 zip。同一个 `installDir` 要两条分支 |
| 素材 | Illustrator 导出的 SVG 用 `<style>.st0{fill:…}` + `class`，**nanosvg 不解析 CSS** → 整块变黑（水印比卡底还暗 3/255）。随程序发布的拷贝要把 `class="st0"` 换成 `fill="#C5C3C0"`，原件不动 |
| 双击 | 不能靠 OS：本机 glfw 的 `win32_window.c` 没有 `WM_LBUTTONDBLCLK` 分支，但真快速双击两次 `onClick` 都会到 → 自己用 420ms 时间窗判 |
| "没变就不写盘"守卫 | 基准**不能取函数入口快照**：`addExe/removeExe/resolveDup` 都是先改 `registry` 再调刷新，入口快照已等于改后值 → 永不写盘（真机表现"新登记的 exe 一重启就没了"）。基准用 `g_regSavedSig`，由 `saveConfig()` 维护 |
| 复用 PXC | `SendInput` 发 `Ctrl+O` **必须分帧**（~120ms/步，GameMaker 按帧轮询键盘）；校验用「目标 `#32770` 对话框消失」，**不能**用 `recent.json`；找主窗不能用 `GetClientRect`（最小化返回 0×0）→ 用 `GetWindowPlacement().rcNormalPosition`；`SW_RESTORE` 是异步 → 轮询 `!IsIconic`（≤1.5s）后再压 150ms |
| 提示窗图标 | nanosvg 光栅化输出**非预乘**，`AlphaBlend` 前要手动预乘；nanosvg 只取声明（自己 define 会 LNK2005）；链 `Msimg32.lib` |
| 侧栏品牌图标 | `components::navbar` 的 `.brand(title, icon)` 第二位是**字形码点**（内部 `.icon(cp)`，字体固定 `"Icon"`），没有图片入口。不 patch vendored `navbar.h`（会变成长期跟框架同步的 patch，同 `contextmenu.h` 的理由），改在根级叠一张矢量图：字形传 `0x20`（空格）把那一行留空，`composeBrandLogo()` 用**同一套 metrics** 算出那块矩形再画 `launcher.svg`——`x=(kNavW-side)/2`（navbar 左右各 `spacing.header` 对称留白，中线就是 navW/2）、`y=spacing.header`、`side=control.menuItem`。`zIndex(2)`：压住 navbar 底，低于浮层（900+）。素材链：`素材/素材-启动器icon.svg` →（`tmp/mkicon.py` 去 `<style>`、`class="st0/1/2"` 换显式 `fill`）→ `launcher/data/icons/launcher.svg` |
| 程序图标 | `launcher/res/app.rc` 一条 `GLFW_ICON ICON "launcher.ico"`：资源名**必须**叫 `GLFW_ICON`（vendored `win32_window.c:1297` 建窗类时按这个名字 `LoadImage`）。三个坑：① `eui_neo_configure_app` 默认会挂 `EUI-NEO-main/assets/icon.ico`（`IDI_APP_ICON`），而 rc.exe 给**每条 ICON 语句的 `RT_ICON` 帧号各自从 1 起** → 两组并存必报 `CVT1100 资源重复: ICON 1` + `LNK1123`，故先 `set_property(GLOBAL PROPERTY EUI_NEO_APP_ICON_RESOURCE "")`；② `.rc` 里中文注释要 `/c65001`，否则 rc.exe 按 GBK 读乱码；③ GLFW 只填 `WNDCLASSEX.hIcon`（32px），`hIconSm` 留空 → 标题栏/Alt+Tab 拿 32 硬缩必糊，要 `pxc_nui::applyWindowIcon()` 按 `SM_CXSMICON` 重取一次（`HICON small` 这种变量名别用：`rpcndr.h` 里 `#define small char`）。ico 是多尺寸包，由 `tmp/mkicon.py` 从 `素材/素材-启动器icon.png`(256) + `素材-启动器icon-x16.ico`(手调) 合成 9 帧 |
| 静默启动 | `dslAppConfig().visible(false)` → `glfwWindowHint(GLFW_VISIBLE)`；`findMainWindow()` 改类名 `GLFW30` 优先 |
| 提示窗字号 | 原生 GDI，**不吃** EUI 的 `fontSize()` 系数 → `pxc_toast::setTextScale()` 显式传倍率；`textPx(dip)=round(DPI缩放×倍率)`，窗口高现算（100%=104，150%=138） |
| 取色面板 | `ColorPickerBuilder` 的 style 默认取 `theme::dark()` → **必须显式 `.theme(uiTheme())`**；必须挂根级 + `.zIndex(1100)`（与 dialog 同为 1000，嵌套时退化成创建顺序） |
| 跨渠道偏好 | 两个触发点：进版本库页可见时 / 双击启动仍没表态（先问再起，中途换页 = 放弃）。打开工程不问。判据 `needPrefAsk()` |
| 拉起 PXC 必须钉 cwd | `CreateProcessW` 第 8 参传 `nullptr` → 子进程继承启动器自己的 cwd，而启动器可能被 `.pxc` 关联从**工程目录**拉起（Explorer 把 cwd 设为文件所在目录）。PXC 的 `APP_LOCATION = working_directory`，四个外部库默认路径是 `%APP%/ffmpeg|gifski|webp|ImageMagick/` → 全落到工程目录 → 「No FFmpeg/gifski/webp/ImageMagick detected」四条误报，导出与 ImageMagick 代理导入全废。**必须显式传 `exePath.parent_path()`**。判别痕迹：相对写出的 `log_temp.txt` 出现在工程目录 |
